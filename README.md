# URL Shortening Service

Setup Instructions

# 1. Clone the repository:
git clone https://github.com/akmal369afzal/muhammad-innovaxel-akmal.git


# 2. Navigate to the project directory:
cd url-shortening-service

# 3. Install dependencies:

npm install

# 4. Create a `.env` file in the root directory and add your MongoDB URI and PORT:

env
MONGO_URI=mongodb+srv://your-username:your-password@cluster0.mongodb.net/your-database-name
PORT=5000

# 5. Run the project:

npm start

Your app should now be running at `http://localhost:5000`.
